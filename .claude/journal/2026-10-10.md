## Decisions

| Decision | Choice | Why |
|---|---|---|
| Architecture | One Go service, API plus a sync worker goroutine | Only the Google call needs isolating. Microservices add deploys and a broker for no gain at this size. |
| Signature | HMAC-SHA256 over `timestamp.body`, 5-minute window | The brief says "secret signature". Ed25519 was considered; it fits many partners better, not one. |
| Duplicates | Match by external ID, then email; ID and email on different leads is 409 | Satisfies R1.3 and R1.4 without silently merging two leads. |
| Sync tracking | `leads.version` vs `lead_sync.synced_version`, one row per lead | Coalesces repeated updates and re-converges after a crash. |
| Packages | `internal/api` holds all handlers instead of `internal/webhook` | Health and OAuth routes are not webhooks. |

## Code review (mattpocock-skills:code-review, standards + spec agents)

Fixed, each with a test that failed first:
- Signature used `c.Body()`, which Fiber decompresses; now `c.BodyRaw()`. Gzipped partner requests would have been rejected.
- Worker held `FOR UPDATE` locks on `lead_sync` across Google calls, blocking intake when Google hung. Now no transaction spans the calls; `MarkSynced` keeps the highest version.
- Backoff `power(2, attempts+1)` overflowed the interval around attempt 43 (confirmed in psql), wedging the row into 2-second retries. Exponent capped at 10.
- Relinking a different account kept an unreachable sheet ID. Now it clears the ID and requeues all leads.
- `invalid_grant` during sheet setup never set `needs_reauth`. Now set (and logged once).
- Spreadsheet and header are created in one API call, so a failed header write can't orphan a sheet.
- `Status` reports `unknown` on a database error instead of `not_linked`. Admin key check deduplicated.
- Removed the SSH key path detail from this journal.

Not fixed, by choice: lowercase-only stage names (documented API), rotated refresh tokens (rare), `Secure` state cookie (breaks http://localhost), Google error text in the browser (useful for the demo), range literals and config tests (low value for a PoC).

Live check after fixes: restarted server, new lead demo-4 synced to the real sheet, no log errors.
